# 💰 Smart Expense Tracker with AI Insights

An intelligent finance management application that not only tracks user expenses but also provides AI-driven insights, anomaly detection, and smart financial recommendations to improve saving habits.

---

## 🚀 Project Overview

Traditional expense trackers only record transactions. This project goes beyond that by:

- Automatically capturing expenses from SMS
- Allowing manual expense entry
- Analyzing user spending behavior
- Detecting unusual transactions
- Providing real-time alerts and predictions
- Motivating users with savings streaks

---

## ✨ Key Features

### 📥 Multi-Source Expense Tracking
- 📱 SMS-based automatic expense detection (bank messages)
- ✍️ Manual expense entry by users
- 🔄 Unified storage of all expenses

---

### 🧠 AI-Powered Insights
- Spending pattern analysis
- Category-wise expense tracking
- Personalized financial suggestions

---

### 🚨 Anomaly Detection
- Detects unusual or suspicious spending
- Alerts user instantly for abnormal transactions

---

### 🔮 Expense Prediction
- Predicts future expenses based on past behavior
- Helps users plan budgets effectively

---

### 🔔 Smart Alerts & Notifications
- Real-time alerts for overspending
- Budget limit warnings
- Savings reminders

---

### 🔥 Savings Streak System (Gamification)
- Tracks consecutive days of controlled spending
- Encourages better financial discipline
- Rewards consistency

---

## 🏗️ System Architecture

1. **Data Collection Layer**
   - SMS Reader API
   - Manual Input UI

2. **Processing Layer**
   - Data cleaning and categorization
   - NLP for SMS parsing

3. **AI Layer**
   - Anomaly Detection Model
   - Expense Prediction Model

4. **Application Layer**
   - User dashboard
   - Alerts and insights display
